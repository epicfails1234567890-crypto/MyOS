Comando para limpiar la pantalla:



; --- Limpiar la pantalla ---
    mov ah, 0x00      ; Función 0x00 del BIOS: Establecer modo de video / reiniciar pantalla
    mov al, 0x03      ; Modo de video estándar: Texto 80x25 con 16 colores
    int 0x10          ; Ejecuta la interrupción de la BIOS (esto borra la pantalla y pone el cursor en 0,0)









Comando para escribir carácter en la pantalla:

    mov ah, 0x0e      ; Función del BIOS para imprimir un carácter en pantalla de forma sencilla
    mov al, 'S'       ; Carácter que queremos imprimir
    int 0x10          ; Llamada a la interrupción de video del BIOS

    mov ah, 0x0e      ; Función del BIOS para imprimir un carácter en pantalla de forma sencilla
    mov al, 'i'       ; Carácter que queremos imprimir
    int 0x10          ; Llamada a la interrupción de video del BIOS
